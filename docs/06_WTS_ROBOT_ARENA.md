## Oracle Verification

The WTS Oracle is the trust layer of the Robot Arena.

Oracle verified means:
- Live performance data pulled directly from MT5 via WTS Nexus EA
- No manual inputs — all statistics are computed
- Performance verified against Firestore trade records
- Any discrepancy flags the robot immediately

Oracle badge: ✓ = trust. No badge = unverified.
Unverified robots cannot be sold in the Marketplace.
