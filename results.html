HOW TO INSTALL IN METATRADER 5

    

      
Step 1 — Download the file
Tap the Download button. Save the .mq5 file to your device.

      
Step 2 — Open MetaEditor
In MetaTrader 5, press F4 or go to Tools → MetaEditor.

      
Step 3 — Move the file
File → Open Data Folder → MQL5 → Experts → paste your file here.

      
Step 4 — Compile
Open file in MetaEditor, press F7. Should show "0 errors, 0 warnings".

      
Step 5 — Attach to chart
Navigator → Expert Advisors → drag EA onto chart → enable AutoTrading.
